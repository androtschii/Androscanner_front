# Androscanner — Frontend

Web-панель сканера собственной сети. React + Vite + Tailwind CSS.

Бэкенд: [Androscanner_back](https://github.com/androtschii/Androscanner_back)

## Стек

- **Vite 8** + **React 19**
- **Tailwind CSS v4** (через `@tailwindcss/vite`, без отдельного конфига)
- **React Router 7**
- **Recharts** — графики на дашборде
- Запросы к API — нативный `fetch`, без axios

## Запуск

```bash
npm install
cp .env.example .env    # при необходимости поправь адрес API
npm run dev
```

Фронт поднимется на http://127.0.0.1:5173

**Важно:** бэкенд должен быть запущен на адресе из `VITE_API_URL`
(по умолчанию http://127.0.0.1:8000), и этот origin должен быть в
`CORS_ORIGINS` бэкенда — иначе браузер заблокирует запросы.

## Страницы

| Путь | Что показывает | Кому |
|---|---|---|
| `/login` | вход | всем |
| `/dashboard` | итоги, статусы, топ сервисов и портов | всем ролям |
| `/scans` | список сканов, запуск нового | запуск — admin и analyst |
| `/scans/:id` | хосты, порты, сервисы, ОС; PDF; отмена | отмена — админ или автор |
| `/network` | карта сети радиальным графом | всем ролям |
| `/diff` | сравнение двух сканов | всем ролям |
| `/profile` | смена собственного пароля | всем ролям |
| `/admin` | allowed scope, пользователи (вкл./откл.), audit-log | только admin |

## Как хранится токен

JWT живёт **только в памяти** React-контекста — ни `localStorage`,
ни `sessionStorage`. Обновление страницы разлогинивает: осознанный выбор
для инструмента, который видит вашу сеть. Токен нельзя украсть через XSS
из хранилища браузера, потому что его там нет.

## Разграничение прав в интерфейсе

Меню и кнопки рендерятся по роли из `/users/me`: viewer не увидит форму
запуска скана, не-админ не увидит ссылку на админку.

Это **удобство, а не защита**. Настоящая проверка прав живёт на бэкенде:
viewer, вручную открывший `/admin`, получит от API `403` на каждый запрос.
Проверено тестами.

## Решения по визуализации

- **Один цвет на все столбцы графика.** Красить их градиентом по величине
  значило бы кодировать длину столбца ещё и оттенком — то же самое дважды.
- **Статусы сканов — подписанные плитки, а не график.** Четыре числа не
  заслуживают графика. Заодно снимается проблема пары зелёный/красный:
  валидатор палитры показал ΔE 4.1 при дейтеранопии, то есть для дальтоника
  «готово» и «ошибка» неразличимы. В плитках цвет лишь дублирует подпись.
- **Палитра прогнана через валидатор** против фактического фона `slate-900`:
  все шесть проверок пройдены.
- **У каждого графика есть таблица-двойник.** Значение никогда не доступно
  только через наведение мыши.
- **Карта сети нарисована инлайновым SVG**, без библиотеки: Recharts уже
  стоил 362 кБ, тащить вторую ради одной страницы неразумно. Карта добавила ~7 кБ.

## Размер сборки

Дашборд загружается отдельным чанком через `lazy`: Recharts весит 362 кБ,
и без разделения он попадал в основной бандл, раздувая его с 255 до 617 кБ.
Теперь за библиотеку платит только тот, кто открыл дашборд.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+K` / `⌘K` | палитра команд — переход и действия без мыши |
| `/` | курсор в поиск на странице сканов |
| `Esc` | очистить поиск, закрыть палитру или диалог |

Палитра написана вручную, а не на `cmdk`: та тянет за собой Radix, а нужны
были фильтрация списка, стрелки и Enter — около ста строк. Тот же довод,
что и для диалогов на нативном `<dialog>` и SVG-карты сети: зависимость
должна окупаться.

## Экспорт в CSV

Список сканов и карта сети выгружаются кнопкой «CSV».

**Про безопасность выгрузки.** Excel и LibreOffice трактуют значение,
начинающееся с `=` `+` `-` `@`, как формулу. Имя хоста и баннер сервиса
приходят из сканируемой сети — их содержимое выбирает не пользователь.
Хост с именем вида `=cmd|'/c calc'!A1` попытался бы выполниться при
открытии файла. Это CSV-инъекция, и для инструмента, собирающего данные
из сети, она реальна, а не теоретична.

Такие значения предваряются апострофом — он делает ячейку текстовой
и не виден при просмотре. Покрыто тестами.

Файл начинается с BOM: без него Excel читает UTF-8 как cp1251,
и кириллица превращается в кракозябры.

## Подтверждение опасных действий

«Отключить пользователя» и «Убрать диапазон» раньше срабатывали мгновенно
по одному клику. Удаление диапазона отзывает право сканировать сеть —
слишком легко сделать случайно. Теперь оба спрашивают, и текст объясняет
последствие, а не просто «вы уверены?».

`ConfirmDialog` построен на нативном `<dialog>`: он сам даёт фокус-ловушку,
закрытие по Escape и затемнение фона.

## Устойчивость к ошибкам

Всё приложение обёрнуто в `ErrorBoundary`. Раньше ошибка рендера белила
страницу целиком без единого слова; теперь показывается текст ошибки
и две кнопки — повторить или уйти на дашборд.

Текст ошибки не прячется за «что-то пошло не так»: пользователь этого
сканера — тот же человек, который его запускает, и заставлять его лезть
в консоль за тем, что можно показать сразу, незачем.

Полезная деталь, всплывшая при написании тестов: **React 19 после
перехвата сам повторяет рендер**, чтобы отличить разовый сбой от
постоянного. Компонент, упавший однажды, восстановится без участия
пользователя.

## Известные ограничения

- **Обновление страницы разлогинивает** — следствие хранения токена в памяти.
- Два предупреждения `oxlint` оставлены осознанно: `AuthContext` экспортирует
  провайдер вместе с хуком (идиоматично для React), а `set-state-in-effect`
  — ложное срабатывание на асинхронной загрузке.
